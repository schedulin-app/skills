# Schedulin agent skills

Agent skills for [Schedulin](https://www.schedulin.app): schedule and publish social media posts to Instagram, TikTok, YouTube, X, LinkedIn, Facebook, Pinterest, Threads, Bluesky, Reddit and more from your AI agent.

## Install

```bash
npx skills add schedulin-app/skills
```

Then set `SCHEDULIN_API_KEY` (create one at https://dashboard.schedulin.app/settings/api-keys).

## Skills

| Skill | Description |
| --- | --- |
| [schedulin](skills/schedulin/SKILL.md) | Post now, schedule, queue, upload media and check scheduled posts through the Schedulin API |

Prefer MCP? Connect `https://mcp.schedulin.app` instead. Full API docs: https://developers.schedulin.app
